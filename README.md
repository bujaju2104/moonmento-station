# 문멘토 역세권 지도

서울 지하철역을 누르면 반경(250m·500m·1km) 안의 아파트 단지를 가까운 순서로 보여 주고, 단지마다 국토부 실거래가 그래프와 거래 내역을 보여 주는 페이지예요.

- 지도: 카카오맵 JavaScript SDK (키는 카카오 개발자 사이트의 JavaScript SDK 도메인에 등록된 주소에서만 작동)
- 지하철역·노선: © OpenStreetMap contributors, ODbL 1.0 (`data/subway.json`은 이 라이선스를 따름)
- 실거래: 국토교통부 아파트 매매 실거래가 (`data/apts.json`, 2025.11~2026.10)
- 단지 위치: 일부는 자료에 포함, 나머지는 카카오 장소 검색으로 찾아 `data/geo.json`에 저장

## 단지 위치 한 번에 채우기
배포 주소 끝에 `?fill`을 붙여 열면(예: `https://moonmento-station.vercel.app/?fill`) 서울 전체 단지 위치를 찾고 `geo.json`을 내려받아요. 그 파일을 `data/geo.json`으로 올리면 모든 사람이 바로 볼 수 있어요.

## 메뉴
- 홈: 이번 주 계약 일정, 지난 일정, 이번 주 확인할 사항(자동), 내 할 일, 최근 대책
- 역세권 지도: 역 반경 단지 + 실거래 그래프(대책 발표일 점선)
- 매물: 광고글·메모 붙여넣기 → 매물별 표 정리, 칸 바로 수정, 엑셀(xlsx) 다운로드
- 계약·달력: 계약서 사진(글자 인식)·PDF·붙여넣기 → 종류·소재지·금액·당사자·날짜 추출 → 확인 후 저장 → 달력·일정·엑셀·휴대폰 달력(.ics)
- AI 도구: 매물 소개글, 광고 필수 표시 점검, 상담 정리, 반론 롤플레이, 손님 시세 브리핑, 특약 초안, 계약 일정 계산기
- 정권별 대책: 2003~2026 대책 54건, 정권·분야별

## 저장
매물·계약·할 일은 브라우저(localStorage)에만 저장돼요. 로그인 버전에서 Supabase 계정 저장으로 옮길 예정.

## 외부 라이브러리 (필요할 때만 불러옴)
SheetJS xlsx 0.18.5 (cdnjs), pdf.js 3.11.174 (cdnjs), tesseract.js 5.1.1 + 한국어 인식 자료 (jsDelivr)

## 손님 (통화녹음 분석)
- 통화녹음을 글자로 바꾼 .txt 파일을 올리거나 대화를 붙여넣으면 이름·연락처·구분·예산·현금·대출·지역·단지·면적·입주 시기·학군·원하는 것·피하는 것·약속 일정을 뽑아요.
- "이번 주 토요일 오후 2시", "다음 주 화요일", "11월 20일" 같은 말은 날짜로 바꿔요. 체크한 약속은 달력·홈에 '상담' 일정으로 들어가요.
- 저장 위치: localStorage `mm-customers-v1`

## 매물 · 재개발 구역별 보기
- 매물 글에 "신당10구역"처럼 구역 이름이 있으면 구역별로 묶어 감정가·추정감정가·프리미엄·승계보증금·실투자금·소유주·전화·네이버 매물번호·지도를 한 번에 보여줘요.

## 홈 · 내 할 일 (말·글로 넣기)
- 🎤 말로 입력(크롬·사파리 음성 인식) / 글 붙여넣기 / 녹음 텍스트(.txt) → "그리고", 줄바꿈, 문장 단위로 나눠 날짜·시간·종류(연락·방문·계약·서류·광고)·중요 표시를 자동 정리.
- 날짜 있는 할 일은 달력과 이번 주 일정에 '할일'로 들어가요.

## AI 도구 · 손님용 시세 브리핑 이미지
